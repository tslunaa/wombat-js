# Wombat.js — мини-клон Quokka для VS Code

Автор: **Цай Ариадна Андреевна**, группа **М3105**

## Описание

Wombat.js — это расширение для Visual Studio Code, которое выполняет JavaScript/TypeScript файл через Node.js inspector и отображает значения глобальных переменных непосредственно в редакторе. Значения выводятся в виде подписей (decorations) справа от строк, где объявлены переменные. Расширение служит учебным примером реализации механизма "живого вывода" в стиле Quokka.js, но построено на собственном взаимодействии с протоколом inspector и API редактора.

## Возможности

- Выполнение текущего JS/TS файла с помощью Node.js inspector.
- Получение списка глобальных переменных и вычисление их значений.
- Поиск строк объявления переменных в исходном тексте.
- Отображение значений переменных в конце соответствующих строк в редакторе.
- Генерация подписей с вычисленными значениями (decorations).
- Возможность полностью очистить все ранее созданные подписи одной командой, без необходимости перезапуска редактора.

## Требования

- Установленный Node.js (LTS версия).

## Использование

Чтобы запустить выполнение файла, откройте любой `.js` или `.ts` файл и выполните команду:
```
Wombat: Run current file
```
## После запуска расширение выполнит несколько шагов:

1. Создаётся новая сессия Node.js inspector.  
2. Код файла компилируется в скрипт и выполняется.  
3. Из контекста inspector извлекается список глобальных переменных.  
4. Для каждой переменной запрашивается её текущее значение.  
5. В документе ищется строка, где эта переменная была объявлена.  
6. Справа от строки появляется подпись вида:

```javascript
x = 42
msg = "hello"
sum = 97
```


Подписи создаются через механизм `TextEditorDecorationType` и не изменяют исходный файл — они существуют только визуально.

## Новый концепт: очистка всех подписей (decorations)

В расширении реализована полноценная команда для удаления всех ранее созданных подписей.

### Зачем это нужно:

- decorations накапливаются — при повторных запусках их становится всё больше;  
- VS Code не очищает Decorations автоматически;  
- большое количество пометок ухудшает читаемость кода;  
- разработчику нужно вернуть документ в исходное визуальное состояние.

Теперь в Wombat.js доступна команда:

```
Wombat: Clear decorations
```


### Как это работает:

1. Расширение хранит список всех созданных `DecorationType`.  
2. При активации команды:
   - decorations очищаются вызовом `editor.setDecorations(type, [])`;  
   - каждый `DecorationType` уничтожается методом `dispose()`.  
3. После выполнения команда полностью убирает все подписи, и документ выглядит «чистым».

Команда особенно полезна при тестировании больших файлов, повторных запусках и анализе промежуточных результатов.

Файл:

```javascript

let b = a * 3;

После выполнения команды Run current file:
```

После выполнения команды **Clear decorations** — все подписи исчезают, и файл снова выглядит как исходный.

## Завершение

Wombat.js является учебной реализацией механики Quokka и демонстрирует работу с Inspector API, TypeScript, VS Code API, `TextEditorDecorationType` и архитектурой расширений.  
В проекте реализованы запуск и анализ кода, отображение результатов, работа с глобальными переменными, создание и очистка.
